# Math

## Inline single dollar

```
Energy is $E = mc^2$ here.
```

**Renders as:**

Energy is $E = mc^2$ here.

## Inline double dollar

```
Energy is $$E = mc^2$$ here.
```

**Renders as:**

Energy is $$E = mc^2$$ here.

## Inline double dollar separate

```
$$E = mc^2$$
```

**Renders as:**

$$E = mc^2$$


## Block

```
$$
E = mc^2
$$
```

**Renders as:**

$$
E = mc^2
$$

## Non math

```
Solar cost $61 ... $76 prose
```

**Renders as:**
